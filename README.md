interactive Mask Tracking Game
About the Project
This is an interactive game I developed for a workshop at my school's technology club. The project combines computer vision, hand tracking, and visual effects inspired by my favourite Marvel characters.
Using a webcam, players can control the game with their hand movements, draw in the air, and create or customise their own masks.

Main Features
Real-time Hand Tracking: Detects and tracks hand movements through a webcam.
Air Drawing: Allows players to draw in the air using their fingertips.
Interactive Mask Creation: Enables users to create and customise masks.
Marvel-Inspired Visual Effects: Incorporates visual designs inspired by Marvel characters.

Technologies Used

OpenCV

Pygame
PyOpenGL
NumPy

How to Run
Download or clone this repository.

Run pip install -r requirements.txt.
Run python main.py.
Allow access to your webcam.
